PROJECT NOTES / 01

ALGOGEM

Strategy in a sealed-bid gem auction.

I built a Python bot using the competition’s provided client. Each turn involves two decisions: how much to bid and which card to reveal. The shared display changes the value of the gems players hold.

How the bot works

  • Records the gems each player wins after every auction.
  • Scores reveal options by comparing my collection with the strongest rival’s holdings of the same color.
  • Accounts for saturation when a color already has five cards in the value display.
  • Uses bidding thresholds tied to auction type and available coins.

Built during Jane Street’s Academy of Math and Programming, 2026.

PROJECT NOTES / 02

Global Flu Tracker

Second place at HackAppleton, 2025.

A team-built JavaScript web application for exploring flu outbreak locations on an interactive map.

What we built

  • A Leaflet map using OpenStreetMap tiles.
  • Toggleable layers for human and animal outbreak locations.
  • Location lookup with Nominatim geocoding.
  • Proximity-based risk scoring using Haversine distance.

This is a hackathon prototype. Its recorded outbreak data and simulated prediction features are not a live public-health feed or medical guidance.
